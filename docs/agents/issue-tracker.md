# Issue tracker: GitHub

Issues and specifications for this repository live in GitHub Issues. Use the `gh` CLI from this repository so it resolves `lltv28/kodara-machine-demo` from the configured remote.

## Conventions

- Create work with `gh issue create`.
- Read the issue body and comments before implementation with `gh issue view <number> --comments`.
- Record meaningful decisions or scope changes on the relevant issue.
- Close an issue only after its acceptance criteria have been verified.
- Pull requests are not treated as a request or triage surface.

## Skill routing

When a skill says to publish to the issue tracker, create a GitHub issue. When a skill says to fetch the relevant ticket, read the corresponding GitHub issue and its comments.

# Domain docs

This repository uses a single domain context.

## Before planning or implementation

- Read `CONTEXT.md` at the repository root when it exists.
- Read relevant decisions under `docs/adr/` when that directory exists.
- Proceed silently when either location does not yet exist.

## Vocabulary

Use the canonical terms defined in `CONTEXT.md`. Add a term only when project-specific language has been resolved. Keep implementation details out of the glossary.

## Decisions

Use an ADR only for a decision that is hard to reverse, surprising without context, and the result of a genuine tradeoff.
